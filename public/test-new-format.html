📋 Format Baru Sistem Antrian

Format: HURUF + 4 DIGIT

Contoh: A0001, B0001, C0001

Hari Huruf Contoh Format
Senin A A0001, A0002, A0003...
Selasa B B0001, B0002, B0003...
Rabu C C0001, C0002, C0003...
Kamis D D0001, D0002, D0003...
Jumat E E0001, E0002, E0003...
Sabtu F F0001, F0002, F0003...
Minggu G G0001, G0002, G0003...
✨ Fitur Utama:
  • ✅ Reset otomatis setiap hari ke nomor 1
  • ✅ Huruf berubah sesuai hari (A-G)
  • ✅ Format lebih profesional dan mudah diingat
  • ✅ 4 digit dengan leading zero (0001, 0002, dst)

🔄 Informasi Migration

Kolom Baru yang Ditambahkan:
  • nomor_urut - Integer untuk query (1, 2, 3, dst)
  • tanggal - Tanggal antrian (2026-05-19, dst)

Kolom yang Dimodifikasi:
  • nomor_antrian - Format display (A0001, B0001, dst)

Fitur Otomatis:
  • ✅ Auto-generate nomor_urut (berurutan per hari)
  • ✅ Auto-generate tanggal (hari ini)
  • ✅ Auto-generate nomor_antrian (format A0001)

📝 Langkah Test

  1. Buka Admin Dashboard dan tambah antrian baru
  2. Perhatikan format antrian yang digenerate (misal: A0001)
  3. Tambahkan beberapa antrian lagi untuk test urutan
  4. Panggil antrian dan dengarkan format di audio
  5. Besok sistem otomatis reset ke B0001 (jika selasa)
